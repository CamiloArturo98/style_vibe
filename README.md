## Installation

Clone the repository:

```bash
git clone https://github.com/CamiloArturo98/style_vibe.git
```

Navigate to the project folder:

```bash
cd style_vibe
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
ng serve
```

Open in browser:

```bash
http://localhost:4200
```
